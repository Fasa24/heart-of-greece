# Heart of Greece

![Heart of Greece Banner](assets/img/heart-of-greece-banner.png)

### A Taste of Home

Traditional recipes, honest ingredients, and generous food made to be shared around the table.

**Heart of Greece** is a static website built with HTML, CSS, and JavaScript.

## 📖 Description

Rooted in traditional Greek cooking, **Heart of Greece** is a place for honest food, warm hospitality, and good company.

We prepare familiar recipes with quality ingredients and the same care we believe they deserve.

Simple food, generously served, and always meant to be shared.

## ⬇️ Getting Started

Clone the repository and open the project locally:

```bash
git clone https://github.com/Fasa24/heart-of-greece.git
cd heart-of-greece
```

Once the repository has been cloned, the project can be viewed using either of the following methods:

- Open `index.html` directly in a web browser.
- Serve the project using a local development server.
